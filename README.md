# Radweg-Check-Karlsruhe
Webkarte, auf der Probleme auf Karlsruher Radwegen gemeldet und übersichtlich dargestellt werden. Zu jeder Meldung können der genaue Standort, eine Kategorie wie Hindernis, eine kurze Beschreibung und das Meldedatum gespeichert werden. Die Daten werden über eine eigene REST-API in einer PostgreSQL-Datenbank gespeichert.
